# My First ML Project – Solubility Prediction 
Tools: Python, pandas, scikit-learn, matplotlib 
Built a foundational machine learning project to predict the aqueous solubility (logS) of molecules using a public dataset of chemical descriptors. 
The workflow included: Loading and exploring a CSV dataset directly from GitHub. 
Separating features (descriptors) from the target variable (logS). Splitting data into training (80%) and test (20%) sets. Training and evaluating two regressors: Linear Regression (baseline) and Random Forest (tree-based). Comparing model performance using Mean Squared Error (MSE) on both training and test data to diagnose overfitting. Visualizing predicted vs. experimental solubility with a scatter plot and fitted polynomial curve to intuitively assess prediction accuracy. This project demonstrates core ML skills: data handling, model training/evaluation, and result comparison.
